# [기획/설계] 게임인생프로필 서비스 (약칭: 겜생프로필)

본 문서는 Pickty 플랫폼에 새롭게 추가될 신규 UGC 콘텐츠인 **게임인생프로필 (약칭: 겜생프로필, GNB 메뉴명: 프로필)**의 기획안 및 연동 아키텍처 설계입니다.

---

## 1. 서비스 개요 및 가치

### 1.1. 기획 배경
기존의 일반적인 전적 조회 서비스들은 오직 승률, KDA, 랭킹 등 **삭막한 계량 데이터만 나열**하여 게이머 개인의 정체성과 감성을 담아내기 부족합니다. 
게임인생프로필(겜생프로필)은 게이머가 자신의 **게임 인생 업적(다양한 플랫폼/장르의 게임 경력)**과 **자유로운 현실 게이머 감성(데스크셋업, 장비 등 사진 업로드)**을 한 장의 **빽빽한 신문 지면 형태의 격자형 대시보드 포스터**로 예쁘게 조립하여 공유할 수 있는 **게이머판 링크트리(Linktree)**를 지향합니다.

### 1.2. 핵심 목적
* **종합 게임 명함 구축**: PC/콘솔/인디/고전 게임을 아우르는 종합 명함 역할.
* **낮은 진입 장벽**: 복잡한 소셜 로그인 과정 없이, 유저가 원하는 ID와 암구호(비밀번호) 입력만으로 즉시 고유 프로필 생성 가능.
* **공유 유도**: 간결한 단축 URL 제공 및 이미지 캡처(다운로드) 기능을 통해 디스코드, 게임 대기실, 커뮤니티 공유 유도.

## 2. 핵심 기획 방향성 (Self-Proven & Hybrid Input)

### 2.1. 자율 인증 및 비회원 주소 ID/비밀번호 선점 시스템
가입 허들을 없애고 쉽게 프로필을 공유할 수 있도록, 비회원도 **[원하는 주소 ID (슬러그)]**와 **[암구호(비밀번호)]**를 입력하여 자신만의 고유 주소를 선점하고 자율적으로 수정할 수 있는 시스템을 제공합니다.

```
[비회원 프로필 최초 생성 시]
유저가 직접 원하는 주소 ID (예: sleep5165)와 암구호(비밀번호)를 입력하여 생성
  └── 생성 완료 시 즉시 나만의 고유 주소 확보: pickty.app/profile/sleep5165

[생성 완료 후 프로필 카드 수정 또는 인증샷 등록 시]
해당 프로필 상세(/profile/sleep5165) 진입 -> [편집/인증 등록] 클릭
  └── 생성 시 설정한 암구호를 검증하여 일치하는 경우에만 데이터 편집 권한 부여
```

* **아바타, 닉네임, 한줄소개 생략**: 유저가 이미 본인의 닉네임이 드러난 채로 외부(디시, 인스타, 롤 로비 등)에 링크나 명함 이미지를 공유하므로 중복되는 표시명 정보는 입력창 및 카드 디자인에서 완전히 배제하여 콤팩트함을 유지합니다.
* **주소 ID(슬러그) 중복 방지**: 프로필 생성 시 이미 사용 중인 ID인지 실시간 중복 체크를 수행하여 유일한 주소 체계를 보장합니다.
* **자율 인증제**: 별도의 어드민 심사 없이 유저가 직접 인증용 스크린샷 이미지들을 프로필 하단의 **[자율 인증 갤러리]**에 자율적으로 업로드하여 보관합니다. 게임 카드별로 개별 매핑되지 않고, 마구잡이로 자유롭게 올려서 증명합니다.
  * 첨부된 인증 스크린샷이 0개인 경우: 카드 하단에 `"인증내역 없음"` 표시.
  * 첨부된 인증 스크린샷이 1개 이상인 경우: 카드 하단에 `"인증있음"` 표시와 함께 공유용 상세 주소 `"pickty.app/profile/{slug}"`를 렌더링.
  * 방문자는 상세 주소로 유입되어 하단에 나열된 인증샷 피드들을 보고 직접 진위 여부(예: 실제 다이아몬드 티어 사진인지, 불펌인지)를 주관적으로 판별합니다.
* **비회원 보관 및 가이드**:
  * 비회원 생성 완료 시: `"프로필 주소가 복사되었습니다! 이 링크(pickty.app/profile/아이디)를 메모장 등에 보관해 두시면 언제든 다시 접속해 수정할 수 있습니다. 매번 보관하고 주소를 찾아오는 과정이 번거로우시다면, [소셜 로그인 연동]을 통해 내 계정에 프로필을 영구 보존하세요!"` 팝업/토스트를 통해 주소 보관 유도 및 소셜 로그인을 강력히 추천합니다.
  * 비회원은 개인정보(이메일 등)를 수집하지 않으므로 비밀번호 분실 시 복구가 불가능함을 화면에 상시 노출합니다.

### 2.2. 하이브리드 데이터 입력 (API + 검색 + AI 자연어 + 수동 Fallback)
모든 게임의 공식 API를 제공하는 것은 불가능하므로, 4가지 경로를 통해 카드 정보를 채웁니다.

| 입력 방식 | 설명 | 대상 예시 | 수집 데이터 |
| :--- | :--- | :--- | :--- |
| **1. 실시간 API 연동** | 공식/비공식 API를 연동하여 아이디 입력만으로 정보 추출 | League of Legends, Overwatch 2 등 | 레벨, 현재 티어, 모스트 챔피언/영웅, 승률 등 |
| **2. DB 검색 기반 입력** | IGDB 등 글로벌 게임 DB 연동을 통한 게임 타이틀 & 썸네일 자동 매칭 | Steam 인디 게임, 콘솔 타이틀 등 (할로우 나이트, 엘든 링) | 타이틀, 공식 키아트(이미지), 유저가 추가한 커스텀 Key-Value 스탯 블록 |
| **3. AI 자연어 입력** | **Gemini 2.5 Flash** 기반의 'AI 3초 만에 카드 생성'. 유저가 자유롭게 작성한 한 줄 텍스트로부터 스탯 카드를 자동 추출/조립 | "나 할나 5문 깼고 스타듀밸리 2500시간 함" 등 | 입력 텍스트로부터 게임 타이틀 식별자, 스탯 항목 및 수치를 AI가 파싱하여 JSON 형태로 자동 반환 |
| **4. Fallback 직접 입력** | DB 검색에도 없는 극소수 고전/모바일/인디 게임 대응 | 커스텀 모드 게임, 동인 게임 등 | 유저가 직접 올린 게임명, 게임 아이콘 이미지, 커스텀 Key-Value 스탯 블록 |

## 3. UI/UX 및 레이아웃 아키텍처 (신문지 격자형 명함 및 상/하 수직 배치)

개별 카드가 무의미하게 쪼개지는 파편화를 탈피하고, **빽빽한 신문 지면 형태의 단일 대시보드 명함 카드(div)**로 연출합니다. 이 카드 영역 하나만 깔끔하게 캡처하여 고화질 이미지 파일로 다운로드할 수 있습니다.

```
┌───────────────────────────────────────────────────────────────────────────┐
│ [ sleep5165의 게임인생프로필 ]                                             │
├─────────────────────────────────────────────┬─────────────────────────────┤
│ 🎮 League of Legends (대표 게임 S급 블록)  │ 🎮 Overwatch 2 (A급 블록)   │
│ (왼쪽 절반 혹은 대형 영역 차지)            │ (우측 상단 배치)            │
│                                             │ - 최고 티어: 다이아몬드    │
│ - 소환사명: sleep5165#KR1                    │ - 모스트: 겐지, 트레이서    │
│ - 현재 티어: 다이아몬드4 (최고 탑레: 마스터) │                             │
│ - 모스트 챔피언: 아리, 제이스, 리신         ├─────────────────────────────┤
│ - 레벨: 520 (승률: 54.2%)                   │ 🎮 Eternal Return (A급 블록)│
│                                             │ (우측 하단 배치)            │
│ [📸 인증샷 첨부됨]                         │ - 티어: 이터니티            │
├─────────────────────────────────────────────┴─────────────────────────────┤
│ 🎮 Hollow Knight (B급 블록 - 하단 가로형 배치)                            │
│ - 업적: 5문 클리어         - 플레이타임: 2500시간                         │
├───────────────────────────────────────────────────────────────────────────┤
│ [인증내역 있음] - pickty.app/profile/sleep5165                            │
└───────────────────────────────────────────────────────────────────────────┘
```

### 3.1. 상단 영역: [신문지 격자형 명함 카드 (단일 div)]
* **카드 타이틀**: `[주소 ID]의 게임인생프로필` 형태로 심플하게 고정 노출합니다.
* **격자형 배치 (Newspaper Grid Layout)**:
  * 유저가 등록한 게임 중 하나를 **'대표 게임(Main Game)'**으로 지정할 수 있습니다.
  * 대표 게임 블록은 격자 내부에서 가장 넓은 크기(예: `col-span-2 row-span-2`)를 차지하며 상세 데이터(부캐, 레벨, 승률, 모스트 챔피언 등)가 빽빽하게 연출됩니다. 
  * API 연동 시 이 대형 메인 블록의 정보가 한 번에 다 채워져 비주얼 밀도를 극대화합니다.
  * 나머지 서브 게임들은 우측과 하단에 조밀한 크기의 격자 블록(`col-span-1`)으로 꼬깃꼬깃 맞물리며 공간을 채워 전체 직사각형 형태를 완성합니다.
* **카드 꼬리말**: 인증 내역 유무(하단 인증 갤러리에 업로드된 사진 유무)에 따라 `[인증있음] - pickty.app/profile/{slug}` 또는 `[인증내역 없음]`이 새겨집니다.
* **[이미지 다운로드]**: 이 명함 카드 영역(`div`)을 타겟팅하여 이미지 파일(PNG/WebP)로 깔끔하게 캡처하여 소장할 수 있게 합니다.

### 3.2. 하단 영역: [현실 피드 & 인증 갤러리 섹션]
* 캡처되는 명함 이미지 **바깥(하단)**에 배치되는 갤러리 영역입니다.
* **현실 피드**: 사용자가 직접 올린 현실 사진(장비, 데스크셋업 등)들이 나열됩니다.
* **인증 갤러리**: 사용자가 자율적으로 올린 인증용 스크린샷 이미지들이 모여있으며, 방문자가 상세 링크를 타고 들어와 직접 진위여부를 확인합니다.


### 3.3. 프로필 메인/검색 페이지 UI 및 로컬스토리지 연동 (`/profile`)
* **검색바 플레이스홀더 정리**: 하드코딩 값 제거 및 입력 힌트(`"프로필 주소 ID 입력 (예: my-nickname)"`) 노출.
* **로컬스토리지 기반 최근 방문/작성 기록 표시**: `localStorage` (키: `pickty_profile_history`) 목록을 로드하여 둥근 배지 형태의 클릭 가능한 버튼들로 나열하고, 배지 우측 내부의 `✕` 버튼으로 개별 삭제를 지원합니다.

## 5. 백엔드 및 데이터베이스 설계 (DB Schema)

### 5.1. ERD 테이블 구조 설계 (GamerProfile)
* 아바타, 표시닉네임, 한줄소개 항목이 기획 스펙아웃됨에 따라, `gamer_profiles` 테이블의 관련 컬럼(`nickname`, `bio`, `avatar_image_url`)을 제거하고 최소한의 식별값 및 보안 해시만 남겨 단순화합니다.
* `gamer_profile_cards` 테이블에 `is_main` (대표게임 여부, BOOLEAN) 컬럼을 추가하여 신문지 레이아웃의 메인 강조 대상을 결정합니다.

```mermaid
erDiagram
    users ||--o1 gamer_profiles : "possesses (0..1)"
    gamer_profiles ||--o{ gamer_profile_cards : "contains"
    gamer_profiles ||--o{ gamer_profile_feeds : "posts"
    gamer_profile_cards ||--o{ gamer_profile_card_stats : "describes"

    gamer_profiles {
        bigint id PK
        bigint user_id FK "Nullable"
        string custom_slug UK "URL 매핑용 고유 슬러그 (예: sleep5165)"
        string guest_password_hash "비회원 수정을 위한 비밀번호"
        string guest_ip_hash "비회원 식별용 IP SHA256 해시"
        timestamp created_at
        timestamp updated_at
    }

    gamer_profile_cards {
        bigint id PK
        bigint profile_id FK
        string game_slug "다국어/속어 표준화 식별을 위한 표준 영문 슬러그 (예: league-of-legends)"
        string game_source "API, SEARCH, AI, DIRECT"
        string game_title "게임명"
        string game_icon_url "게임 로고/아이콘 이미지 URL"
        string external_api_identifier "API 연동 식별값"
        boolean is_main "대표 게임 여부 (레이아웃 강조 제어)"
        int display_order
        timestamp updated_at
    }

    gamer_profile_feeds {
        bigint id PK
        bigint profile_id FK
        string image_url "R2 업로드 이미지 URL"
        string description "사진 캡션"
        string feed_type "REALITY, PROOF"
        int display_order
        timestamp created_at
    }
```
